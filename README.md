# ✈️ Jornada Viagens

Site institucional fictício de uma agência de viagens, desenvolvido com foco em boas práticas de **HTML5**, **CSS3**, **SEO on-page** e **design responsivo Mobile First**.

> Projeto fictício sem fins comerciais.

---

## 🚀 Tecnologias

- **HTML5** — estrutura semântica e acessível
- **CSS3** — layout responsivo com Grid e Flexbox
- **SEO on-page** — meta tags, Open Graph e títulos otimizados
- **Mobile First** — desenvolvido prioritariamente para dispositivos móveis

---

## 📋 Páginas

| Página | Descrição |
|--------|-----------|
| `index.html` | Página inicial com ofertas, categorias, destinos e depoimentos |
| `pacotes.html` | Página de pacote específico (Japão — Tóquio e Osaka) |

---

## ✨ Funcionalidades

- Layout **100% responsivo** (mobile, tablet e desktop)
- Menu hambúrguer funcional via CSS puro
- Seção de **ofertas da semana** com cards ilustrados
- **Destinos populares** com imagens de fundo responsivas
- Seção de **condições de pagamento** com galeria de imagens
- **Depoimentos** de clientes
- Meta tags de **Open Graph** para compartilhamento em redes sociais
- Favicon customizado em SVG
